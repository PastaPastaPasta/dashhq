    Learn how it works

    Start with what Platform does, then explore its machinery.

    What is Dash Platform?

    Dash Core moves DASH and secures payments. Platform adds shared application data: an identity gives an app a public account, a username makes that account easier to find, and documents hold things like a post or a poll. A data contract sets the rules for those documents.

    Evonodes are masternodes that run Platform. They agree on updates and provide proofs so your browser can check an answer against the network’s signed state. A valid proof confirms the stored data; it does not establish that a post is true or an app is safe.
