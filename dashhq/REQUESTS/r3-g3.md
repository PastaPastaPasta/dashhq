# g3 adoption observations

## Container plus page header resets centering

Shell 1.4.0: combining `.dh-container` and `.dh-page-header` on one element sets its margin-inline to zero because the page header's `margin: 0 0 var(--dh-6)` shorthand comes later. At desktop 1440, a 1200px container starts at x=0 and its heading at x=40 instead of x=160. Radar now nests the header inside the container, consistent with the documented recipe. Consider preserving inline margins in the page header rule or documenting this combination explicitly as unsupported.

## Resolved in 1.4.1

The page header now sets only block margins, preserving the container's auto inline margins when both classes share an element. Nested headers keep the same spacing. The component geometry checks cover both forms at desktop and phone widths.
